1

สร้าง LINE Official Account แต่ละตัว (ทำซ้ำ 11 ครั้ง)

~5 นาที/ตัว
💡 เคล็ดลับ: เปิด browser หลายแท็บพร้อมกัน ทำ Bot 1 ก่อน ทดสอบให้ผ่านก่อน แล้วค่อยทำที่เหลือตามแบบเดิม
1

เปิด LINE Developers Console

ไปที่ developers.line.biz แล้ว Log in ด้วย LINE account ของคุณ (account หลักที่ใช้บริหารจัดการ)

แนะนำ: ใช้ 1 LINE account เดียวสร้างทุก Bot เพื่อจัดการง่าย
2

สร้าง Provider (ครั้งแรกครั้งเดียว)

กด "Create a new provider" → ตั้งชื่อ: กระทรวง อว. MHESI → กด Create

⚠️ ถ้ามี Provider อยู่แล้วสำหรับ อว. ให้ใช้อันเดิมได้เลย ไม่ต้องสร้างใหม่
3

สร้าง Messaging API Channel

ใน Provider → กด "Create a Messaging API channel"

กรอกข้อมูล:

Channel name: [ดูตารางด้านบน เช่น "MHESI AI Assistant"] Channel description: [ดูตารางด้านบน] Category: Government / Public sector Subcategory: Government service Email: [อีเมลของคุณ] Privacy policy URL: https://g2g-ai-pool.fly.dev/platform-overview.html Terms of use URL: https://g2g-ai-pool.fly.dev/platform-overview.html

✓ ยอมรับ Terms of use → กด Create

4

คัดลอก Channel Access Token (Long-lived)

ไปที่แท็บ "Messaging API" → เลื่อนลงหา "Channel access token (long-lived)"

กด "Issue" → คัดลอก token ที่ได้ (ยาวมาก ~170 ตัวอักษร)

⚠️ สำคัญ: บันทึก Token ไว้ในไฟล์ข้อความก่อน เพราะแสดงครั้งเดียว ถ้าปิดหน้าต้อง Issue ใหม่
5

ตั้ง Webhook URL

ยังอยู่ที่แท็บ Messaging API → หา "Webhook URL"

กด Edit → วาง URL ตามบอทที่สร้าง:

# Bot 1 (ปลัดศุภชัย): https://g2g-ai-pool.fly.dev/line/webhook/MHESI01 # Bot 2: https://g2g-ai-pool.fly.dev/line/webhook/MHESI02 # Bot 3-11: เปลี่ยนเลขท้ายตามลำดับ https://g2g-ai-pool.fly.dev/line/webhook/MHESI03 ... https://g2g-ai-pool.fly.dev/line/webhook/MHESI11

เปิด toggle "Use webhook" → กด Update → กด Verify

✅ ถ้าขึ้น "Success" แปลว่า Bot เชื่อมต่อ server แล้ว
6

ปิด Auto-reply Messages

ไปที่ manager.line.biz → เลือก OA ที่เพิ่งสร้าง

ไปที่ Settings → Response settings

Response mode: → เลือก "Bot" Auto-response: → ปิด (OFF) Greeting message: → ปิด (OFF) หรือตั้งเองก็ได้
✅ สำคัญมาก — ถ้าไม่ปิด Auto-reply จะตอบ template แทน AI
2

ตั้งค่า Fly.io Secrets — ใส่ Token ทุก Bot

~5 นาที

วาง Token ของแต่ละ Bot ด้านล่าง แล้วกดสร้างคำสั่ง — copy-paste ไปรันใน Terminal ทีเดียวเลย

วิธีรันคำสั่ง:
1. เปิด Terminal (Cmd+Space → พิมพ์ Terminal)
2. วาง (Cmd+V) คำสั่งที่คัดลอกมา → กด Enter
3. รอ Fly.io อัปเดต (~30 วินาที) → Bot พร้อมรับ Token ใหม่ทันที ไม่ต้อง Deploy ใหม่
3

ทดสอบ Bot ก่อนใช้งานจริง

~10 นาที
A

ทดสอบผ่านหน้า Admin Panel

เปิด g2g-ai-pool.fly.dev/mhesi-bot-admin.html (password: mhesiadmin2026)

เลือก Bot → พิมพ์ข้อความทดสอบ → กด ส่ง → ดู AI ตอบกลับ (ไม่ต้องผ่าน LINE)

B

ทดสอบใน LINE จริง

ใน LINE Developers Console → แท็บ Messaging API → เลื่อนหา QR Code

สแกน QR เพื่อเพิ่ม Bot เป็น Friend → ส่งข้อความทดสอบ
