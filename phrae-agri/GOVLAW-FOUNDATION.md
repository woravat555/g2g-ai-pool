## ๒. แผนคน (People Plan) — โครงสร้าง HR ตามกฎหมาย

### ๒.๑ ประเภทบุคลากรภาครัฐ (ตาม พ.ร.บ.ข้าราชการพลเรือน 2551)

```
ข้าราชการพลเรือนสามัญ (Civil Servant)
  ├── สายงานวิชาการ  → วิชาการเกษตร / วิชาการส่งเสริมการเกษตร
  ├── สายงานอำนวยการ → เจ้าพนักงานธุรการ / เจ้าพนักงานการเงิน
  └── สายงานบริการ   → พนักงานขับรถ / ช่างภาพ

พนักงานราชการ (Government Employee)
  ├── กลุ่มบริการ    → ปฏิบัติงาน 4 ปี ต่อสัญญาได้
  └── กลุ่มวิชาการ  → เฉพาะทาง

ลูกจ้างประจำ (Permanent Employee)
  └── ตำแหน่งในบัญชีอัตราค่าจ้างลูกจ้างประจำ

จ้างเหมาบริการ (Service Contract) ← ไม่มีสถานะข้าราชการ
  ├── รายเดือน       → จ้างเต็มปีงบประมาณ (ต.ค. – ก.ย.)
  ├── รายวัน         → งานชั่วคราว/ฤดูกาล
  └── รายโครงการ     → จ้างตามผลงาน (Output-based)

อาสาสมัคร (Volunteer) ← ไม่มีสถานะบุคลากรภาครัฐ
  └── อกม. (อาสาสมัครเกษตรหมู่บ้าน) — ได้รับค่าตอบแทนพิเศษจากงบโครงการ
```

### ๒.๒ กรอบอัตรากำลัง 3 ปี
- ส่วนราชการต้องจัดทำ "กรอบอัตรากำลัง 3 ปี" (ทุก 3 ปีงบประมาณ)
- กำหนดจำนวนอัตรา ประเภท ระดับ ตำแหน่ง
- **ระบบต้องรู้ว่าแต่ละคนเป็นประเภทไหน** เพราะสิทธิ์/งบที่เบิกได้ต่างกัน

### ๒.๒ โครงสร้างสายบังคับบัญชา (พ.ร.บ.บริหารราชการแผ่นดิน มาตรา 11, 18, 20)
```
รัฐมนตรีว่าการ  →  รัฐมนตรีช่วย  →  ปลัดกระทรวง
    │
    ├── [เกษตรและสหกรณ์จังหวัด] ← สังกัดสำนักงานปลัดกระทรวง
    │       บทบาท: ประสาน บูรณาการ ภาพรวมทุกหน่วยในจังหวัด
    │       ไม่ใช่ผู้บังคับบัญชาสายตรงของกรมต่างๆ
    │
    └── อธิบดี/เลขาธิการ (แต่ละกรม)
            │
            └── หัวหน้าส่วนราชการจังหวัด (เกษตรจังหวัด/ปศุสัตว์จังหวัด ฯลฯ)
                    │
                    └── [กรมส่งเสริมการเกษตรเท่านั้น]
                            └── เกษตรอำเภอ (8 อำเภอ)
                                    └── นักวิชาการเกษตรตำบล
                                            └── อกม. (ระดับหมู่บ้าน 641 หมู่บ้าน)
                                                    └── เกษตรกร ~65,000 ราย
```

## ๓. แผนเงิน (Finance Plan) — งบประมาณแผ่นดินตามหมวดรายจ่าย

### ๓.๑ หมวดรายจ่าย 5 หมวด (ตาม พ.ร.บ.วิธีการงบประมาณ 2561 + ภาคผนวก กรมบัญชีกลาง)

```
หมวด ๑ — งบบุคลากร
  ├── เงินเดือน (ข้าราชการ)
  ├── ค่าจ้างประจำ (ลูกจ้างประจำ)
  ├── ค่าจ้างชั่วคราว (ลูกจ้างชั่วคราวจากเงินนอกงบประมาณ)
  └── เงินเพิ่มต่างๆ ตามสิทธิ

หมวด ๒ — งบดำเนินงาน
  ├── หมวดย่อย ค่าตอบแทน
  │       ├── ค่าตอบแทน อกม. (เบี้ยเลี้ยงอาสาสมัคร)
  │       ├── ค่าตอบแทนคณะกรรมการ
  │       └── ค่าตอบแทนผู้ปฏิบัติงานให้ราชการ
  ├── หมวดย่อย ค่าใช้สอย
  │       ├── ค่าจ้างเหมาบริการ ← ตรงนี้!
  │       │       ├── รายเดือน (สัญญาเต็มปี/ครึ่งปี)
  │       │       ├── รายวัน  (ค่าแรงงาน)
  │       │       └── รายโครงการ (จ้างเฉพาะงาน Output-based)
  │       ├── ค่าเช่า (รถ/เครื่องมือ)
  │       └── ค่าพาหนะ ที่พัก เบี้ยเลี้ยง
  ├── หมวดย่อย ค่าวัสดุ (สำนักงาน/เกษตร/ยานพาหนะ)
  └── หมวดย่อย ค่าสาธารณูปโภค

หมวด ๓ — งบลงทุน
  ├── ค่าครุภัณฑ์ (อายุใช้งาน >1 ปี มูลค่า >5,000 บ.)
  ├── ค่าที่ดิน
  └── ค่าก่อสร้าง/ปรับปรุงสิ่งก่อสร้าง

หมวด ๔ — งบเงินอุดหนุน
  ├── อุดหนุนทั่วไป (อปท.)
  └── อุดหนุนเฉพาะกิจ (โครงการระบุวัตถุประสงค์)

หมวด ๕ — งบรายจ่ายอื่น
  ├── เงินราชการลับ
  └── เงินสำรองจ่าย
```

### ๓.๒ แหล่งเงิน (Source of Fund)
```
๑. งบประมาณแผ่นดิน        ← ตาม พ.ร.บ.งบประมาณรายจ่ายประจำปี
๒. เงินนอกงบประมาณ        ← เงินกองทุน / ค่าธรรมเนียม
๓. เงินกู้                ← โครงการขนาดใหญ่ (อนุมัติ ครม.)
๔. เงินช่วยเหลือจากต่างประเทศ ← ต้องผ่าน กพร./สำนักงบ
```

### ๓.๓ กฎสำคัญ: จ้างเหมาบริการ (ตาม พ.ร.บ.จัดซื้อจัดจ้าง 2560)
```
วงเงินไม่เกิน 100,000 บ. → ใช้วิธีเฉพาะเจาะจง
วงเงิน 100,001–500,000 บ. → ใช้วิธีสืบราคา (e-price)
วงเงินเกิน 500,000 บ.    → ประกวดราคา (e-bidding)

สัญญาจ้างเหมาบริการ:
- ทำสัญญาหรือข้อตกลงตามระยะเวลาจริง
- ไม่เกินปีงบประมาณ (ต่ออายุได้ปีต่อปี)
- ผู้รับจ้างรับผิดชอบงานเองทั้งหมด (ไม่ใช่ลูกจ้าง)
- ไม่มีสิทธิ์สวัสดิการข้าราชการ
```

## ๔. แผนงาน/โครงการ (Work & Project Plan)

### ๔.๑ ลำดับชั้นแผน
```
ยุทธศาสตร์ชาติ 20 ปี (2561-2580)
    │
    ├── แผนแม่บทภายใต้ยุทธศาสตร์ชาติ (23 ประเด็น)
    │
    ├── แผนพัฒนาเศรษฐกิจและสังคมแห่งชาติ ฉ.13 (2566-2570)
    │
    ├── แผนปฏิบัติราชการกระทรวง (4 ปี + ปีต่อปี)
    │       └── แผนปฏิบัติราชการกรม (4 ปี + รายปี)
    │               └── แผนปฏิบัติงาน + งบประมาณรายปี
    │
    └── แผนพัฒนาจังหวัด (5 ปี) ← ผู้ว่าฯ เป็นประธาน
            └── แผนปฏิบัติราชการจังหวัด (รายปี)
                    └── โครงการ ← ขอรับงบผ่าน สำนักงบประมาณ
```

### ๔.๒ โครงสร้าง "โครงการ" ที่ถูกต้องตามระเบียบ
```
โครงการ 1 โครงการ ประกอบด้วย:
├── วัตถุประสงค์ (Objective)
├── เป้าหมาย/ตัวชี้วัด (KPI)
├── กิจกรรม (Activities) — 1+ กิจกรรม
│       ├── กิจกรรมที่ 1: ฝึกอบรม
│       │       ├── งบบุคลากร: ค่าวิทยากร → หมวด ค่าตอบแทน
│       │       ├── งบดำเนินงาน: ค่าเช่าสถานที่ → หมวด ค่าใช้สอย
│       │       └── งบดำเนินงาน: วัสดุฝึก → หมวด ค่าวัสดุ
│       └── กิจกรรมที่ 2: จ้างเหมาสำรวจแปลง
│               └── งบดำเนินงาน: ค่าจ้างเหมา → หมวด ค่าใช้สอย
├── ระยะเวลา (Timeline)
├── หน่วยงานรับผิดชอบ (Owner)
└── งบประมาณรวม (Budget Summary by หมวด)
```

## ๕. แผนบูรณาการ (Integration Plan)

### ๕.๑ ประเภทแผนบูรณาการ
```
๑. แผนงานบูรณาการระดับชาติ
   → ครม. กำหนด เชื่อมหลายกระทรวง
   ตัวอย่าง: แผนบูรณาการพัฒนาพื้นที่ระดับภาค

๒. แผนบูรณาการจังหวัด (Cluster Model)
   → ผู้ว่าราชการจังหวัด เป็น CEO จังหวัด
   → รวมโครงการจากทุกส่วนราชการในจังหวัด
   → เป้าหมายร่วม วัดผลร่วม

๓. แผนบูรณาการกลุ่มจังหวัด
   → กลุ่มจังหวัด 18 กลุ่ม (แพร่ อยู่กลุ่มภาคเหนือตอนบน 2)
```

### ๕.๒ บทบาทของ "เกษตรและสหกรณ์จังหวัด" ในการบูรณาการ
```
ตามกฎหมาย: ไม่มีอำนาจสั่งการกรมต่างๆ โดยตรง
แต่มีบทบาท:
  ├── ประสานแผนงานเกษตรทุกหน่วยในจังหวัด
  ├── เสนอแผนบูรณาการต่อผู้ว่าฯ
  ├── ติดตามผลการดำเนินงาน
  └── รายงานปลัดกระทรวง

เครื่องมือบูรณาการ:
  ├── คณะกรรมการเกษตรและสหกรณ์จังหวัด (กกจ.)
  ├── แผนพัฒนาการเกษตรจังหวัด
  └── ระบบข้อมูล (ซึ่งนี่คือสิ่งที่ G2G กำลังสร้าง!)
```

## ๖. ผลกระทบต่อการออกแบบระบบ G2G AgriPhrae

### ๖.๑ ฐานข้อมูลที่ระบบต้องมี (ตามหลักบริหารราชการแผ่นดิน)

```
[แผนคน] — ตาราง Personnel
  fields: ชื่อ, ประเภทบุคลากร, ตำแหน่ง, สังกัด(กรม), ระดับ,
          วันที่เริ่มงาน, ประเภทสัญญา(ถ้าจ้างเหมา), อัตราค่าจ้าง

[แผนเงิน] — ตาราง Budget
  fields: ปีงบประมาณ, หน่วยงาน, แผนงาน, โครงการ,
          หมวดรายจ่าย(1-5), รายการ, งบที่ได้รับ, เบิกจ่ายแล้ว,
          แหล่งเงิน, วันที่อนุมัติ

[แผนงาน] — ตาราง Projects  
  fields: รหัสโครงการ, ชื่อโครงการ, หน่วยงานเจ้าของ, ปีงบ,
          เป้าหมาย(KPI), งบรวม, ความก้าวหน้า(%), สถานะ,
          แผนงานที่สังกัด

[แผนบูรณาการ] — ตาราง IntegrationPlan
  fields: ชื่อแผน, หน่วยงานร่วม[], เป้าหมายร่วม, ตัวชี้วัดร่วม,
          ผู้ประสาน, สถานะ, รายงานล่าสุด

[จ้างเหมา] — ตาราง ServiceContracts
  fields: ชื่อผู้รับจ้าง, ประเภท(รายเดือน/รายวัน/รายโครงการ),
          งานที่จ้าง, โครงการที่สังกัด, อัตรา, สัญญาเริ่ม, สัญญาสิ้นสุด,
          วงเงิน, วิธีจัดซื้อ(เฉพาะเจาะจง/สืบราคา/ประกวดราคา)
```

### ๖.๒ กฎที่ระบบต้องบังคับใช้ (Business Rules)

```
BR-01: ค่าจ้างเหมา ต้องตั้งในหมวด "ค่าใช้สอย" ของงบดำเนินงาน
       ห้ามตั้งในงบบุคลากร (เพราะไม่ใช่ข้าราชการ)

BR-02: วงเงินจ้างเหมา >100,000 ต้องมีเลขที่จัดซื้อจัดจ้าง
       ระบบต้องมีช่อง "เลขที่ e-GP"

BR-03: อกม. ได้รับค่าตอบแทนจาก "หมวดค่าตอบแทน" ไม่ใช่เงินเดือน
       และไม่นับในกรอบอัตรากำลัง

BR-04: โครงการ 1 โครงการ มีได้หลายหมวดรายจ่าย
       ระบบต้องแสดง breakdown ตามหมวด

BR-05: แผนบูรณาการต้องระบุ "หน่วยงานเจ้าภาพ" และ "หน่วยร่วม"
       เกษตรและสหกรณ์จังหวัด = ผู้ประสาน ไม่ใช่เจ้าภาพทุกแผน
```

## ๗. บทสรุป — สิ่งที่ต้องสร้างในระบบ (Priority Order)

```
Phase 1 — แผนคน (Personnel Module)
  ✅ ทะเบียนบุคลากรแยกประเภท (ข้าราชการ/พนักงาน/จ้างเหมา/อกม.)
  ✅ สายบังคับบัญชาตามกฎหมาย
  ✅ กรอบอัตรากำลัง

Phase 2 — แผนเงิน (Budget Module)
  ⬜ งบประมาณแยกหมวด 5 หมวด
  ⬜ ติดตามการเบิกจ่าย
  ⬜ จ้างเหมาบริการ (รายเดือน/รายวัน/รายโครงการ) + e-GP reference

Phase 3 — แผนงาน (Project Module)
  ⬜ ทะเบียนโครงการ + KPI
  ⬜ ความก้าวหน้าโครงการ
  ⬜ เชื่อมโครงการ → งบ → ผู้รับผิดชอบ

Phase 4 — แผนบูรณาการ (Integration Dashboard)
  ⬜ ภาพรวมทุกหน่วยงานในจังหวัด
  ⬜ KPI ร่วม
  ⬜ รายงานต่อผู้ว่าฯ / ปลัดกระทรวง
```
