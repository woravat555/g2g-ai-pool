ตั้งค่า LINE Messaging API

⚠️ Token จะถูกใช้งานฝั่ง server เท่านั้น — ไม่ได้บันทึกผ่านหน้าเว็บนี้ด้วยเหตุผลด้านความปลอดภัย
https://g2g-ai-pool.fly.dev/webhook/line

ไปที่ LINE Developers Console → Channel → Messaging API → Webhook URL → วาง URL นี้ → Verify

รัน commands นี้ใน terminal:
fly secrets set LINE_CHANNEL_ACCESS_TOKEN=your_token_here --app g2g-ai-pool fly secrets set LINE_CHANNEL_SECRET=your_channel_secret --app g2g-ai-pool

จากนั้น Fly.io จะ restart app โดยอัตโนมัติ token จะพร้อมใช้งานทันที

เจ้าหน้าที่เพิ่ม LINE OA เป็นเพื่อน → AI จะถามชื่อ-ตำแหน่งอัตโนมัติ → เจ้าหน้าที่พิมพ์ "ใช่" → ยืนยันแล้ว → รับ briefing ทุกเช้า

หรือ Admin link ด้วยตนเองผ่านปุ่ม "🔗 Link ด้วยตนเอง" ในส่วน LINE Users ด้านบน

เลือกตำแหน่งด้านบนก่อน แล้วกดส่ง LINE ทันที — ระบบจะแสดงผลว่าสำเร็จหรือมีข้อผิดพลาดอะไร

✅ ระบบตั้ง setTimeout scheduler ไว้แล้วใน server.js — จะรัน /api/briefing/daily-run ทุกวันเวลา 08:00 น. ตามเวลาไทย (01:00 UTC)

ดู log ด้วย: fly logs --app g2g-ai-pool | grep briefing-scheduler
