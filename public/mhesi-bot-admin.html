    🔑 Fly.io Secrets — ตั้งค่า Environment Variables

    ตั้งค่า LINE Channel Access Token ทั้ง 11 ตัวผ่าน Fly.io CLI — แต่ละตัวได้จาก LINE Developers Console → Messaging API → Channel Access Token (long-lived)

    ตั้งค่าทีละตัว (แนะนำ):
    # ตั้งค่าทีละ Bot flyctl secrets set LINE_TOKEN_MHESI01=your_token_here flyctl secrets set LINE_TOKEN_MHESI02=your_token_here flyctl secrets set LINE_TOKEN_MHESI03=your_token_here flyctl secrets set LINE_TOKEN_MHESI04=your_token_here flyctl secrets set LINE_TOKEN_MHESI05=your_token_here flyctl secrets set LINE_TOKEN_MHESI06=your_token_here flyctl secrets set LINE_TOKEN_MHESI07=your_token_here flyctl secrets set LINE_TOKEN_MHESI08=your_token_here flyctl secrets set LINE_TOKEN_MHESI09=your_token_here flyctl secrets set LINE_TOKEN_MHESI10=your_token_here flyctl secrets set LINE_TOKEN_MHESI11=your_token_here
    ตั้งค่าพร้อมกันทุกตัว (one-liner):
    flyctl secrets set LINE_TOKEN_MHESI01=xxx LINE_TOKEN_MHESI02=xxx LINE_TOKEN_MHESI03=xxx LINE_TOKEN_MHESI04=xxx LINE_TOKEN_MHESI05=xxx LINE_TOKEN_MHESI06=xxx LINE_TOKEN_MHESI07=xxx LINE_TOKEN_MHESI08=xxx LINE_TOKEN_MHESI09=xxx LINE_TOKEN_MHESI10=xxx LINE_TOKEN_MHESI11=xxx
    หมายเหตุ: หลังตั้งค่า secrets แล้ว Fly.io จะ restart container อัตโนมัติ Bot พร้อมใช้งานภายใน 30 วินาที
