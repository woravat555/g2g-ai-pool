ขั้นตอนการสร้าง LINE Official Account

📱
⚠️
ต้องสร้าง LINE OA แยกกัน 11 บัญชี สำหรับแต่ละ Bot — ทำซ้ำขั้นตอนนี้ 11 ครั้ง
  1. 1
    เข้าสู่ LINE Business Manager ไปที่ manager.line.biz แล้ว Login ด้วยบัญชี LINE ขององค์กร (แนะนำให้ใช้อีเมลราชการ)
  2. 2
    สร้าง Account ใหม่ คลิก "สร้างบัญชี" → เลือกประเภท "Messaging API" (ไม่ใช่ LINE Official Account แบบทั่วไป เพื่อให้รองรับ Webhook)
  3. 3
    กรอกชื่อ Account ตั้งชื่อตาม Bot เช่น "ผู้ช่วยปลัดศุภชัย — กระทรวง อว." หรือ "น้องอาว อว." ชื่อนี้จะแสดงใน LINE ของผู้ใช้
  4. 4
    เลือกหมวดหมู่ เลือก "หน่วยงานภาครัฐ" หรือ "การศึกษา" ตามบริบทของ Bot
  5. 5
    ขอสถานะ Verified Account (สำหรับราชการ) ไปที่ LINE Business Center → ยื่นคำขอ Verified Badge โดยแนบเอกสารราชการ (หนังสือรับรองหน่วยงาน) เพื่อได้ตราสัญลักษณ์ความน่าเชื่อถือ
  6. 6
    บันทึก Channel ID และ Channel Secret หลังสร้างเสร็จ ให้คัดลอก Channel ID, Channel Secret และ Channel Access Token เก็บไว้ใช้ในขั้นตอนถัดไป
✅
เสร็จสิ้น: ทำขั้นตอนข้างต้นซ้ำอีก 10 ครั้งสำหรับ MHESI02–MHESI11 แล้วรวบรวม Token ทั้งหมดก่อนไปขั้นตอนต่อไป

ตั้งค่า Webhook สำหรับแต่ละ Bot

🔗
  1. 1
    เข้า LINE Developers Console ไปที่ developers.line.biz → Login → เลือก Provider ขององค์กร → คลิกที่ Channel ที่ต้องการตั้งค่า
  2. 2
    เปิดแท็บ Messaging API คลิกที่ "Messaging API" tab → เลื่อนลงไปส่วน "Webhook settings"
  3. 3
    กรอก Webhook URL ตาม Bot ใช้ URL ตามตารางด้านล่าง แล้วกด "Update"
  4. 4
    เปิดใช้งาน Webhook Toggle "Use webhook" ให้เป็น ON แล้วกด "Verify" เพื่อทดสอบการเชื่อมต่อ — ต้องได้ผลลัพธ์ Success
  5. 5
    ปิด Auto-reply และ Greeting message ในส่วน "LINE Official Account features" → ปิด Auto-reply messages เพื่อให้ Bot AI ตอบแทน (ไม่เช่นนั้น LINE จะตอบอัตโนมัติแทน AI)

ตั้งค่า Fly.io Secrets — Channel Access Token

🔐

ทุก Bot ต้องการ Channel Access Token จาก LINE Developers Console เก็บเป็น environment secret บน Fly.io ใช้คำสั่ง flyctl ดังนี้:

ตั้งค่า Token ทีละตัว (ปลอดภัยสูงสุด)

# ตั้งค่า Token สำหรับ Bot 1 (ปลัดศุภชัย) flyctl secrets set LINE_TOKEN_MHESI01=<Channel_Access_Token_01> --app g2g-ai-pool # Bot 2 flyctl secrets set LINE_TOKEN_MHESI02=<Channel_Access_Token_02> --app g2g-ai-pool # Bot 3 flyctl secrets set LINE_TOKEN_MHESI03=<Channel_Access_Token_03> --app g2g-ai-pool # ... ทำซ้ำสำหรับ MHESI04 ถึง MHESI11 ... # Bot 11 flyctl secrets set LINE_TOKEN_MHESI11=<Channel_Access_Token_11> --app g2g-ai-pool

ตั้งค่าทีเดียวหลายตัว (รวดเร็ว)

flyctl secrets set \ LINE_TOKEN_MHESI01=<token_01> \ LINE_TOKEN_MHESI02=<token_02> \ LINE_TOKEN_MHESI03=<token_03> \ LINE_TOKEN_MHESI04=<token_04> \ LINE_TOKEN_MHESI05=<token_05> \ LINE_TOKEN_MHESI06=<token_06> \ LINE_TOKEN_MHESI07=<token_07> \ LINE_TOKEN_MHESI08=<token_08> \ LINE_TOKEN_MHESI09=<token_09> \ LINE_TOKEN_MHESI10=<token_10> \ LINE_TOKEN_MHESI11=<token_11> \ --app g2g-ai-pool

ตรวจสอบว่า Secrets ถูกบันทึกแล้ว

flyctl secrets list --app g2g-ai-pool
⚠️
ข้อควรระวัง: Channel Access Token มีอายุ และต้อง Generate ใหม่จาก LINE Developers Console เมื่อหมดอายุ ควรตั้ง Expiry เป็น "ไม่มีกำหนดหมดอายุ" (Stateless) หรือ ตั้ง Long-lived token เพื่อลดภาระการจัดการ
✅
หลังตั้งค่า Secrets แล้ว Fly.io จะ Restart app อัตโนมัติ ไม่ต้อง Deploy ใหม่ — Bot พร้อมใช้งานทันที

ทดสอบระบบและแก้ไขปัญหา

🧪

การทดสอบเบื้องต้น

  1. 1
    เพิ่ม Bot เป็นเพื่อน สแกน QR Code จาก LINE Developers Console หรือค้นหาด้วย Line ID ของ Bot
  2. 2
    ส่งข้อความทดสอบ พิมพ์ "สวัสดีครับ" หรือ "ทดสอบระบบ" — Bot ควรตอบกลับภายใน 3 วินาที
  3. 3
    ทดสอบคำถามเฉพาะทาง ลองถามเกี่ยวกับบทบาทของ Bot นั้น เช่น น้องวิจัย → ถามเรื่องทุน ววน.

กรณี Bot ไม่ตอบ — ขั้นตอนวิเคราะห์ปัญหา

🔍
ตรวจสอบ Fly.io Logs ก่อนเสมอ:
# ดู logs แบบ real-time flyctl logs --app g2g-ai-pool # กรอง error เฉพาะ flyctl logs --app g2g-ai-pool | grep ERROR # ดูสถานะ app flyctl status --app g2g-ai-pool

ตารางแก้ไขปัญหาพบบ่อย

ปัญหาสาเหตุที่เป็นไปได้วิธีแก้
Bot ไม่ตอบเลย Webhook ไม่ถึง Fly.io ตรวจสอบ Webhook URL ใน LINE Console ให้ถูกต้อง
ตอบว่า "ขออภัย" Token หมดอายุ / ไม่ถูกต้อง Generate Token ใหม่ → flyctl secrets set
Verify ล้มเหลว App ไม่ทำงาน / URL ผิด flyctl status → ตรวจสอบ app running
ตอบช้ากว่า 10 วิ Instance sleeping / cold start ตั้งค่า min_machines_running = 1 ใน fly.toml
Bot ตอบผิดบุคลิก Channel ID routing ผิด ตรวจสอบ routing logic ใน server code

คุณสมบัติพิเศษของระบบ AI Bot

✨
🧠
User Memory ข้ามการสนทนา
Bot จดจำชื่อ ตำแหน่ง และบริบทของผู้ใช้แต่ละคน ทำให้การสนทนาครั้งต่อไปราบรื่นและเป็นส่วนตัวมากขึ้น
🏛️
ฐานความรู้กระทรวง อว.
Bot รู้ข้อมูลครบถ้วน — กฎหมาย พรบ. 5 ฉบับ, งบประมาณ, หน่วยงานในสังกัด 50+ แห่ง, มหาวิทยาลัย 170 แห่ง
💬
ตอบได้ไม่จำกัดหัวข้อ
บริหารองค์กร, กฎหมายราชการ, วิชาการ, งานวิจัย, ทุนการศึกษา, นวัตกรรม, และให้บริการประชาชนทั่วไป
⚡
ตอบเร็วภายใน 3 วินาที
ใช้ Claude AI ผ่าน Fly.io ภูมิภาค Asia-Pacific ลด latency — เหมาะสำหรับการใช้งานในราชการที่ต้องการความรวดเร็ว
🔒
ปลอดภัยระดับองค์กร
Secret management บน Fly.io, ไม่มีการเก็บบทสนทนาใน server, รองรับ LINE Signature Verification ทุก request
🎯
บุคลิกเฉพาะทางต่อหน่วยงาน
แต่ละ Bot มี System Prompt ที่กำหนดบุคลิก ความเชี่ยวชาญ และกลุ่มเป้าหมายชัดเจน เพื่อตอบตรงจุดที่สุด
🚀
พร้อมใช้งาน: เมื่อตั้งค่าครบทั้ง 3 ขั้นตอน (สร้าง OA → ตั้ง Webhook → บันทึก Secret) ระบบจะพร้อมให้บริการทันที สามารถเพิ่มบุคลากรเข้ากลุ่มหรือแชร์ QR Code ได้เลย
