🖥️ G2G Multi-Device Cowork

ระบบ sync งานระหว่าง 2 Mac โดยใช้ GitHub เป็น shared source of truth

GitHub Repo ✅ LIVE
https://github.com/woravat555/g2g-ai-pool
Fly.io App ✅ DEPLOYED
https://g2g-ai-pool.fly.dev

Machine A (เครื่องหลัก) ✅ Setup แล้ว

Git repo อยู่ที่ ~/Desktop/g2g-ai-pool — commit + push ขึ้น GitHub แล้ว

หลังแก้งาน รัน:

cd ~/Desktop/g2g-ai-pool
git add -A
git commit -m "แก้ไข: อธิบายสิ่งที่เปลี่ยน"
git push

Deploy ขึ้น Fly.io:

fly deploy -a g2g-ai-pool

Machine B (เครื่องที่ 2) ⏳ ต้องทำครั้งเดียว

1
ติดตั้ง Git, Node.js, Fly CLI (ถ้ายังไม่มี)
nodejs.org | brew install git flyctl
2
Clone repo — เปิด Terminal แล้วรัน: 
git clone https://github.com/woravat555/g2g-ai-pool.git ~/Desktop/g2g-ai-pool
cd ~/Desktop/g2g-ai-pool
npm install
3
เปิด Cowork → คลิก "Select Folder" → เลือก ~/Desktop/g2g-ai-pool
4
Login Fly.io (ถ้ายังไม่ได้ login): 
fly auth login

🔄 Workflow ประจำวัน

สถานการณ์ คำสั่ง
เริ่มงานวันใหม่บน Machine B git pull
หลังแก้งาน (เครื่องไหนก็ได้) git add -A && git commit -m "..." && git push
Deploy ขึ้น Fly.io fly deploy -a g2g-ai-pool
ดู log แบบ realtime fly logs -a g2g-ai-pool

⚡ Quick Commands

Script สำหรับ Machine B (ดาวน์โหลดแล้วรัน):

curl -O https://g2g-ai-pool.fly.dev/SETUP-MACHINE-B.sh
chmod +x SETUP-MACHINE-B.sh
./SETUP-MACHINE-B.sh

Script จะ clone repo + npm install ให้อัตโนมัติ
