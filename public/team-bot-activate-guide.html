1
เปิด Messaging API สำหรับ 8 บัญชี
manager.line.biz → แต่ละบัญชี → ตั้งค่า → Messaging API → เปิดใช้งาน
🔗 ทำใน LINE OA Manager
เปิดทีละบัญชี ทำ 3 อย่างเหมือนกันทุกตัว
①
เข้า manager.line.biz → คลิกชื่อบัญชี → แถบซ้าย "ตั้งค่า"
ทำซ้ำทั้ง 8 บัญชี: @gemphrae, @thaidelicious, Phuket, @aisapphire, @aiculture, @aiwood, เพื่อนไทย, AIM Clinic
②
ตั้งค่าการตอบกลับ → ตั้งให้ถูกต้อง
• แชท (Chat) → ปิด
• Webhook → เปิด
• ข้อความตอบกลับอัตโนมัติ → ปิด
③
Messaging API → "เปิดใช้งาน Messaging API"
ถ้าเห็นปุ่ม "เปิดใช้งาน" หรือ "กำลังใช้งาน" → เปิดแล้วข้ามได้ | ถ้ายังไม่เปิด → กดปุ่มเปิด → เลือก Provider "G2G" → ยืนยัน
2
ดึง Channel ID + Channel Secret + Token
developers.line.biz → ทำทีละ Channel → คัดลอก 3 ค่า
🔑 ทำใน LINE Developers Console
เข้า developers.line.biz/console/ → เลือก Provider "G2G" → ทำทุก Channel
①
Basic settings → Channel ID
คัดลอกตัวเลข Channel ID (เช่น 2007312345) — ใช้ตรงนี้แทน LINE_CHANNELID
②
Basic settings → Channel secret
คัดลอก Channel secret (32 ตัวอักษร hex)
③
Messaging API tab → Channel access token → Issue
กดปุ่ม Issue เพื่อสร้าง Long-lived token → คัดลอก token ทั้งหมด (ยาวมาก)
📥 ใส่ค่าด้านล่างนี้ทีละ bot:
3
ตั้ง Fly.io Secrets + Webhook อัตโนมัติ
กด Generate แล้ว copy คำสั่ง → วางใน Terminal
⚡ Copy-Paste Terminal
กรอกข้อมูลใน Step 2 ครบแล้วกดปุ่มนี้ → จะได้คำสั่งพร้อม run
4
ตั้ง Webhook URL ใน LINE Developers Console
paste URL → Verify → Success → ทดสอบ DM
🔗 ทำใน Developers Console
Webhook URL สำหรับทุก bot เหมือนกัน:
https://g2g-ai-pool.fly.dev/webhook/line/mt
①
Messaging API tab → Webhook settings
ใส่ URL → Update → Verify → ต้องขึ้น "Success"
②
Use webhook → เปิด (ON)
toggle ให้เป็นสีเขียว
③
ทดสอบ: DM bot แล้วพิมพ์ "ทดสอบ"
bot ควรตอบเป็น persona ของสมาชิกทีม (Claude Opus 4.6)
