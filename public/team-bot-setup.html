🤖 G2G Team Bot Setup

ผู้ช่วย AI ประจำตัว 8 คน — ใส่ Token แล้ว Active ทันที

ความคืบหน้า: 0/8 บัญชี
วิธีดึง Channel ID + Secret + Token (ต่อ 1 bot)

1เปิด developers.line.biz/console

2เลือก Provider → เลือก Channel ของ bot นั้น

3แท็บ Basic settings → คัดลอก Channel ID

4แท็บ Basic settings → คัดลอก Channel secret

5แท็บ Messaging API → กด Issue (Channel access token) → คัดลอก

6นำค่ามาใส่ใน Setup tab ด้านซ้าย

ตั้งค่า LINE OA Manager (ต่อ 1 bot)

1เปิด manager.line.biz → เลือก OA

2⚙️ ตั้งค่า → ตั้งค่าการตอบกลับ

3แชท → ปิด

4Webhook → เปิด

5ตอบกลับอัตโนมัติ → ปิด

เปลี่ยนชื่อ OA (เลือกบัญชีที่ว่าง)

1เปิด manager.line.biz → เลือก OA ที่ว่าง

2⚙️ ตั้งค่า → ข้อมูลบัญชี

3เปลี่ยนชื่อเป็น: AI เกมส์ - G2G, AI วรรณ - G2G ฯลฯ

📋 คำสั่ง fly secrets — paste ใน Terminal

แก้ XXXX เป็นค่าจริง แล้ว paste ทีเดียวได้เลย

🔍 วิธีหา LINE OA ที่ว่าง (ไม่ได้ใช้งาน)

เปิด manager.line.biz → ดูรายชื่อบัญชีทั้งหมด


สัญญาณที่บอกว่า "ว่าง":

• มีเพื่อน 1 คน (แค่เจ้าของ)

• รูปโปรไฟล์เป็น ไอคอนสีเทา default ไม่มีรูป

• ไม่มี dot สีเขียว (webhook ยังไม่ได้เปิด)


บัญชีที่เห็นแล้วว่าว่าง (จากหน้า 2):

• "woravat" (1 เพื่อน, ไม่มีรูป) → เปลี่ยนชื่อเป็น AI เกมส์ - G2G
