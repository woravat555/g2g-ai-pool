3 หลัง Activate — ตั้ง Webhook + Response Settings

  1. ใน LINE Developers Console → แต่ละ Channel → Messaging API tab → Webhook URL:
    https://g2g-ai-pool.fly.dev/webhook/line/mt
    → กด Verify → กด Update
  2. ใน LINE Manager → แต่ละบัญชี → ตั้งค่าการตอบกลับ:
    Chat: OFF | Webhook: ON | Auto-response: OFF
  3. ทดสอบ: DM แต่ละบอท พิมพ์ "ทดสอบ" → ต้องได้รับการตอบกลับจาก AI
