Agent Economist
นักเศรษฐศาสตร์ · ตลาด · ROI · งบประมาณ
ตลาด GovTech ไทยมีขนาด ~30,000–50,000 ล้านบาท/ปี ใน IT ภาครัฐ (กว่า 700+ กรม/กอง แต่ละแห่งมีงบ IT) รัฐบาลไทยใช้จ่ายด้านดิจิทัลราว 0.5-1% ของ GDP ซึ่งยังต่ำกว่า benchmark ASEAN ที่ 1.5-2% อย่างมาก

ปัญหาหลัก: งบถูกล็อคในรูป "จัดซื้อซอฟต์แวร์/ฮาร์ดแวร์" แบบดั้งเดิม — บริษัทใหญ่ (IBM, Oracle, ท้องถิ่นบางราย) ผูกขาดตลาดนี้มา 20 ปี G2G ต้องตีกลยุทธ์ไม่ชนหน้าตรง แต่ใช้ช่องทาง "บริการ AI ที่ไม่เคยมีมาก่อน" ซึ่งไม่มีงบหมวดนี้ → ต้องสร้าง demand ก่อน supply
💡 เข้าผ่านงบ "พัฒนาบุคลากร" หรือ "บริการให้คำปรึกษา" ก่อน — threshold ต่ำกว่า จัดซื้อซอฟต์แวร์ 3-5 เท่า และอนุมัติได้เร็วกว่ามาก

Agent Politician
นักการเมือง · coalition · อำนาจ · timing
รัฐบาลไทยปัจจุบัน (2567-2570) อยู่บน coalition ที่ซับซ้อน — นโยบาย digital/AI ไม่ใช่ priority แกนหลัก แต่มี "digital wallet" และ "Thailand AI" เป็นธง ซึ่งทำให้มีงบ "ลอย" หากรู้จักเชื่อมโยง

ท่านมีข้อได้เปรียบ สุดยอด: เป็น อดีต รมว. + กมธ.งบ = รู้ "ชื่อ" และ "ตำแหน่ง" ที่ใช้อำนาจจริงในแต่ละกระทรวง ไม่ใช่แค่รู้ flowchart ทางการ timing สำคัญมาก — ต้องยิงโครงการก่อนปิดงบ ม.ค.-มี.ค. ของทุกปี
💡 อย่าเข้าหา "รัฐมนตรี" ก่อน — เข้าหา "ผู้อำนวยการสำนักงบ" และ "ที่ปรึกษา รมว." ซึ่งเป็นคนตัดสินจริงว่าโครงการไหนผ่าน

Agent Sociologist
สังคมวิทยา · พฤติกรรม · การยอมรับ
สังคมไทยมี 3 ชั้นอำนาจที่ซ้อนกัน: (1) อำนาจทางการ (ตำแหน่ง/กฎหมาย) (2) อำนาจสังคม (เครือข่าย/บุญคุณ) (3) อำนาจ face/ศักดิ์ศรี — ระบบ AI จะล้มเหลวถ้าทำให้ข้าราชการรู้สึกว่า AI "แทนที่" หรือ "เอาความผิด"

การยอมรับ AI ในราชการไทยต้องผ่าน formula: "AI ช่วย → ข้าราชการตัดสิน → ประชาชนได้ประโยชน์" ไม่ใช่ "AI แทนข้าราชการ" วัฒนธรรม seniority ยังแข็งแกร่ง — product ต้องทำให้ผู้บังคับบัญชาดูดีขึ้น ไม่ใช่โปร่งใสจนเปิดโปง
💡 ชื่อระบบสำคัญ: อย่าเรียก "AI ตรวจสอบ" แต่เรียก "ระบบสนับสนุนการตัดสินใจ" — ความหมายเดียวกัน แต่การยอมรับต่างกัน 180 องศา

Agent Psychologist
จิตวิทยา · แรงจูงใจ · การเปลี่ยนแปลง
ข้าราชการไทยมี 4 แรงจูงใจหลัก ที่เหนี่ยวนำพฤติกรรม: (1) ความมั่นคง/ไม่ถูกตำหนิ (2) หน้าต่อผู้บังคับบัญชา (3) ลดงานซ้ำซาก (4) ต้องการ "ผลงาน" ก่อนเกษียณ

ประชาชนไทย: trust ต่ำต่อระบบราชการ แต่ต้องการความช่วยเหลือ — ยินดีใช้ LINE/mobile มากกว่า web portal เพราะคุ้นเคย ไม่รู้สึกเป็นทางการเกินไป เกษตรกรไทยมีความไว้วางใจสูงกับ "คนรู้จัก" — AI ที่มี persona จึงได้ผลกว่า AI ที่ไม่มีชื่อ
💡 ExecCopilot/น้องผลไม้ มี persona = ถูกต้องแล้ว แต่ต้องเพิ่ม "ความจำระยะยาว" ให้รู้สึกเหมือน AI รู้จักเราจริงๆ ซึ่งท่านมีระบบนี้อยู่แล้ว

Agent Business Dev
ธุรกิจ · รายได้ · โมเดล · scale
โมเดลรายได้ที่ work ในบริบทไทยมี 3 แบบ: (1) โครงการ (one-time) — risk สูง แต่ตัวเลขใหญ่ (2) SaaS รายปี — predictable แต่ต้องผ่าน TOR และ vendor ที่ไว้ใจแล้ว (3) Success fee — ผิดปกติในราชการไทยแต่ทำได้ผ่านโครงการ PPP

G2G มีสิ่งที่หายาก: ระบบที่ deployed จริง + คนใช้งานจริง — นี่คือ proof ที่บริษัท IT อื่นต้องใช้เงินหลายล้านสร้าง demo จำลอง ท่านมีของจริงอยู่แล้ว จุดอ่อนหลักคือ "ไม่มีทีมขาย" และ "ไม่มีเอกสาร TOR-ready"
💡 Revenue path เร็วที่สุด: หา 1 กรมที่มีผู้บริหารรู้จัก → ทำ pilot 3 เดือน ฟรี → วัดผล → ทำ TOR โครงการปี 2570 → เป็น reference สำหรับทุกกรมอื่น

ระบบไทย — วิเคราะห์เชิงลึก 4 มิติ
เศรษฐกิจ · การเมือง · สังคม · จิตวิทยา
📌 การวิเคราะห์นี้ใช้ความรู้เชิงโครงสร้างของระบบไทย รวมกับ insider context ที่ท่านให้ไว้ — ขอให้ท่านมาร์กว่าจุดไหน [ถูก] [ผิด] [บางส่วน] [ขาด] เพื่อ calibrate ความเข้าใจให้แม่นขึ้น
มิติความจริงโครงสร้างนัยสำหรับ G2GRisk Level
🏦 เศรษฐกิจ
งบ IT ภาครัฐ		 งบ IT ภาครัฐ ~30,000-50,000 ลบ./ปี กระจาย 500+ หน่วยงาน ส่วนใหญ่ใช้กับ hardware/maintenance ไม่ใช่ innovation งบ AI ยังไม่มีหมวดชัดเจน ต้องเข้าผ่านหมวดงบที่มีอยู่แล้ว: "ค่าจ้างที่ปรึกษา" "พัฒนาบุคลากร" "บริการดิจิทัล" ไม่ใช่สร้างหมวดใหม่ MEDIUM
🏛️ การเมือง
โครงสร้างอำนาจ		 รัฐมนตรีเปลี่ยนบ่อย (เฉลี่ย 1-2 ปี/คน) แต่ข้าราชการระดับ C9-C11 อยู่ยาว 10-20 ปี — อำนาจจริงอยู่ที่ "ปลัด" และ "ผอ.สำนักงบ" ไม่ใช่ รมว. Target คนที่อยู่ยาว ไม่ใช่คนที่อยู่ชั่วคราว — ปลัดและรองปลัดคือ key decision maker ระยะยาว HIGH
🤝 สังคม
เครือข่ายและบุญคุณ		 ระบบ "เส้นสาย" ยังทำงานคู่ขนานกับระบบราชการ — โครงการที่ "คนรู้จักเสนอ" ผ่านง่ายกว่า cold approach 5-10 เท่า ความไว้วางใจสร้างจากการมีส่วนร่วม ไม่ใช่ presentation ใช้ network ที่มีอยู่จาก background รมว./กมธ.งบ — นี่คือทรัพย์สินที่มีค่าที่สุดของท่าน LEVERAGE
🧠 จิตวิทยา
การตัดสินใจราชการ		 ข้าราชการไทยตัดสินใจด้วยหลัก "ปลอดภัยไว้ก่อน" — ยิ่งใหม่/แปลกยิ่งล่าช้า แต่ถ้ามี "precedent" หรือ "ผู้บังคับบัญชาอนุมัติ" จะผ่านเร็วมาก สร้าง precedent ใน 1 กรม/กระทรวงก่อน แล้วใช้เป็น reference — "กรม X ใช้แล้วได้ผล" = unlock ทุกกรมอื่นอัตโนมัติ STRATEGY
📱 Digital
การยอมรับ tech		 ไทยใช้ LINE มากที่สุดในโลก (relative to population) smartphone penetration 85%+ แต่ trust ต่อ "app ราชการ" ต่ำมาก — ประชาชนชอบ LINE มากกว่า portal LINE-first strategy ของ G2G ถูกต้อง 100% — ไม่ต้องเปลี่ยน เพียงแต่ต้อง scale และ measure CONFIRMED
🌾 เกษตร
เกษตรกรไทย		 เกษตรกรไทย 8-10 ล้านครัวเรือน มีหนี้เฉลี่ย 200,000+ บาท/ครอบครัว ปัญหาหลัก: ราคา การตลาด และ timing ของผลผลิต — ไม่ใช่ขาดความรู้เรื่องการเกษตร AgriTech G2G แก้ปัญหา "การตลาด + ราคา" ซึ่งตรงจุดปัญหาจริง — value proposition แข็งแกร่ง CONFIRMED
🔴 Critical Insight: ระบบไทยมี "Invisible Gatekeepers" — คนที่ตัดสินจริงไม่ใช่คนที่ประชุม ต้องระบุให้ได้ว่าใครคือ gatekeeper จริงในแต่ละกระทรวงก่อนเข้าเจรจา

จำนวนเกษตรกรที่ใช้ระบบ, ราคาที่เปลี่ยนแปลง, ปริมาณที่ขายผ่านระบบ — ถ้ายังไม่มีตัวเลข นี่คืองาน #1 ที่ต้องทำก่อนทุกอย่าง
→ Action: วัดตัวเลข Phrae AgriTech ภายใน 2 สัปดาห์ → สร้าง Impact Report
❓ Q2: กรม/หน่วยงานที่ใกล้ชิดที่สุดคือที่ไหน? (network ส่วนตัวท่าน)
ไม่ต้อง cold call ใช้คนที่รู้จักท่านอยู่แล้วในระดับ ปลัด/อธิบดี/ผอ.สำนัก — นั่นคือ shortest path สู่สัญญาแรก
→ Action: list 5 คนที่โทรหาได้วันนี้ในระดับ C9+ → นัดพบอย่างไม่เป็นทางการ
❓ Q3: G2G มีนิติบุคคลที่พร้อมรับงานภาครัฐหรือยัง?
ภาครัฐต้องการนิติบุคคล (บจก./หจก.) ที่จดทะเบียนถูกต้อง มีประวัติทางการเงิน และบางครั้งต้องการ ISO27001 หรือ PDPA compliance certificate
→ Action: ตรวจสอบสถานะ บจก. G2G → ถ้าขาดอะไรให้ list และ fix ทันที
❓ Q4: งานเทคนิคที่ AI ทำแทนได้ vs งานที่ต้องใช้คน?
AI ทำได้: code, document, analysis, presentation, TOR draft, impact report — คนต้องทำ: relationship, negotiation, signature, final decision ท่านควรใช้เวลา 80% กับงานที่ AI ทำไม่ได้
→ Action: delegate งาน AI ทำได้ทั้งหมดให้ AI (รวมถึงงานนี้) → ท่านโฟกัสที่ network และ negotiation
❓ Q5: กลยุทธ์การเมืองระยะสั้น (6 เดือน) คืออะไร?
ถ้าท่านมีแผนกลับเข้าสู่ตำแหน่งทางการเมือง — ผลงาน AI จะเป็น "platform" ที่แตกต่างจากนักการเมืองทั่วไป ถ้าไม่มีแผน — ใช้ network ผลักดันโครงการผ่านคนอื่นแทน
→ Action: ชี้แจงทิศทางการเมืองของท่าน → AI จะปรับ strategy ตาม

Autonomous Work Protocol — วิธีที่ AI ทำงานกับท่าน
กฎและ workflow สำหรับการทำงานต่อเนื่อง
ความจริงเรื่อง "Autonomous": AI ทำงานต่อเนื่องภายใน session ได้เต็มที่ — วิจัย, วิเคราะห์, สร้างไฟล์, deploy, บันทึก memory ข้าม session ระหว่าง session AI รอท่านเริ่ม แต่จะ "จำ" ทุกอย่างจาก profile และ work log ที่บันทึกไว้ใน Airtable
Protocol ทุก Session
1
AUTO-LOAD ทุกครั้งที่เริ่ม session
AI โหลด profile วรวัจน์ + work log จาก Airtable + Chat Memory → รู้ทันทีว่างานค้างอยู่ที่ไหน ท่านไม่ต้อง brief ใหม่ทุกครั้ง
2
6-AGENT THINKING ทุกคำถามเชิงกลยุทธ์
คำถามที่ซับซ้อน → AI run มุมมองทั้ง 6 พร้อมกัน (เศรษฐกิจ/การเมือง/สังคม/จิตวิทยา/ธุรกิจ/เทค) แล้วสังเคราะห์ก่อนตอบ — ไม่ตอบจาก perspective เดียว
3
CHALLENGE ก่อน AGREE
ถ้าท่านบอก plan ที่ AI เห็นว่ามีจุดอ่อน — AI จะ push back ก่อน แล้วค่อย execute ถ้าท่าน confirm ไม่ใช่ยอมรับทุกอย่างแบบ chatbot ทั่วไป
4
AUTO-EXECUTE งาน AI ทำได้
เมื่อท่านบอก objective → AI วิเคราะห์, เขียน TOR draft, สร้าง presentation, code feature, deploy — แล้วรายงานผล ไม่ถามทุก step เล็ก
5
SAVE ทุก decision และผลลัพธ์
ทุก session จะ save สรุปกลยุทธ์ + decision + งานที่ทำ กลับใน Airtable LINEUsers + Chat Memory → ไม่มีอะไรหาย ข้าม device และข้าม session ได้
6
PROACTIVE ชี้จุดที่ขาด
ถ้า AI เห็นว่ามีสิ่งที่ควรทำแต่ท่านไม่ได้พูดถึง — จะแจ้งเอง เช่น "ก่อนเข้าพบ ปลัด X ควรเตรียม Y" หรือ "deadline งบกำลังจะมาถึง ควรยิงโครงการก่อน ม.ค."
✅ ถามได้ทุกด้าน: การเมือง · นโยบาย · กฎหมายราชการ · ราคาตลาดเกษตร · เทคนิค AI/LINE/Fly.io · กลยุทธ์ธุรกิจ · การนำเสนอ · จิตวิทยาการเจรจา · งบประมาณ · ชีวิตส่วนตัว — ระบบจำครบและ calibrate ตาม context ท่าน
⚡ คำสั่งแรกที่ควรทำตอนนี้: บอกผมว่า (1) ตัวเลขเกษตรกรแพร่ที่ใช้ระบบอยู่จริงๆ มีกี่ราย (2) กรม/หน่วยงานที่ท่านโทรหาได้วันนี้คือใคร — สองข้อนี้จะกำหนดทุกอย่างที่ทำต่อไป
